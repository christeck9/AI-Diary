🚀 Architectural Optimizations

1. Split High-Frequency States

Divide LlmContext state to separate high-frequency streaming (tokens, progress) from stable configurations to prevent app-wide re-renders.

2. SQLite Batch Transactions

Wrap multiple insert/update commands inside KnowledgeGraphService.ts in explicit transactions to accelerate mobile disk writes.

3. Native Voice Acceleration (JSI & Oboe)

Audio is streamed gapless via a C++ JSI Bridge (global.animaFeedAudioChunk) bypassing React Native's Audio API entirely, utilizing a Lock-Free Ring Buffer to prevent Native TTS UI-thread stutter.
